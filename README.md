# 雪球只认脚印

雪地里的邮差要穿过松林、冰湖和山闸，把包裹送进木屋。身后的雪球会沿着邮差留下的脚印追上来，也能压下邮差踩不动的开关。

## 试玩

用浏览器打开 `index.html`，点击「开始投递」。

- 方向键或 WASD 移动。手机和平板可用屏幕方向键。
- R 重跑当前关卡，Esc 暂停或继续。移动后开始计时。
- 按照编号引雪球压下开关，再前往亮灯的木屋。踩上蓝冰会继续向前滑。
- 成功送达获得一星。收齐邮戳和在目标时间内送达各加一星。
- 通关后会解锁下一关。开启「显示我的最佳路线」可以和自己的最快路线一起跑。

六关的通关成绩、星级和最佳路线保存在当前浏览器。页面支持离线运行。

## 代码

- `levels.js` 定义六张地图、目标时间和雪球追踪距离。
- `engine.js` 提供独立于浏览器的移动、机关、碰撞和评级逻辑。
- `renderer.js` 用 Canvas 绘制地形、脚印、角色和雪粒。
- `game.js` 处理输入、音效、暂停、界面和本地存档。

运行 `node --test` 可验证所有六关都有三星路线，并检查雪球碰撞、开关顺序与冰面滑动。
